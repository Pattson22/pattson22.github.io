01 — About

From operations leadership to cloud automation

I'm Patrick, a Cloud Engineer and BSc Computer Science student at GISMA University of Applied Sciences. I specialise in building and operating cloud-native architectures on AWS, using Infrastructure as Code with Terraform to make environments reproducible, auditable, and fast to ship.

My engineering principle is simple: automate everything that repeats. I lean on CI/CD pipelines to remove manual toil, design with security and reliability in mind, and instrument systems so problems surface before users notice them.

I came into tech from a background in operations and team leadership, which left me with strong instincts for risk management, process discipline, and clear documentation — habits that translate directly into running production infrastructure responsibly.

01 Flagship

Multi-tier Cloud Application (CloudHub)

Designed and deployed a three-tier web application on AWS, provisioned entirely with Terraform. The architecture separates web, application, and database tiers across public and private subnets, with security groups enforcing least-privilege traffic. Docker containerises each service, and GitHub Actions runs the build, test, and deploy pipeline on every push.

What I learned: how to model an entire environment as code so it can be torn down and rebuilt identically in minutes.
